# FotoManager – Offizielle Releases (Windows 11)

Offizielles Download- und Update-Repository für **FotoManager** – den nativen Windows-11-Foto- & Videomanager im Lightroom-CC-Stil für lokale Ordner und SMB-NAS-Bibliotheken.

## Aktuelle Version: `v2.8.6`

- **Windows-Installer (64-Bit):** [`FotoManager-Setup-2.8.6-win-x64.exe`](https://github.com/Tollator/foto-manager-releases/releases/download/v2.8.6/FotoManager-Setup-2.8.6-win-x64.exe)
- **Alle Releases & Änderungsprotokoll:** [GitHub Releases](https://github.com/Tollator/foto-manager-releases/releases)

## Systemvoraussetzungen & Update-Sicherheit

- **Betriebssystem:** Windows 11 (x64)
- **Installation:** Doppelklick auf den Installer – inkl. .NET 8 Runtime, Windows App SDK, lokaler ONNX-KI-Modelle und PDF-Handbuch (keine Zusatz-Installation nötig).
- **Update-Sicherheit:** Bestehende Einstellungen, Katalog-Datenbank, API-Schlüssel (lokal per Windows DPAPI) und NAS-Daten (`.fotomanager/`) bleiben bei jedem Update vollständig erhalten.

> *Hinweis: Dieses öffentliche Repository stellt ausschließlich die geprüften Windows-Installer und Release-Beschreibungen bereit (stets die neuesten 3 Releases).*
